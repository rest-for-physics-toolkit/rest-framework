Detailed Description

Event container holding all digitized waveforms of one acquisition trigger.

Each signal is a vector of 16-bit ADC samples identified by its signal ID (the DAQ channel, decoded into a readout channel by the detector library). The samples are stored contiguously (TRestRawSignalData) and accessed through TRestRawSignal views. In the event tree (named TRestRawSignalEvent) the signals are written in the branches fSigSamples, fSigIDs and fSigOffsets, besides the ones of TRestEvent.

Signal IDs are unique in an event: AddSignal ignores, with a warning, an ID that already exists. Adding or removing signals invalidates the references returned by GetSignal.
