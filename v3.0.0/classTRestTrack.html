Detailed Description

Lightweight view of one track of a TRestTrackEvent: the event and the index of the track in it.

It stores no hits: every getter reads the shared storage of the event, so a TRestTrack is valid only while the event exists and its tracks are not added or removed. A default constructed track (or one returned when no track matches, e.g. TRestTrackEvent::GetMaxEnergyTrack) has no event: test it with GetEvent() != nullptr. On an invalid track the getters return empty values (no hits, 0 energy, ID -1; the hit index of GetSigmaX/Y/Z(localHitIdx) is not checked).

TRestTrack track = event->GetMaxEnergyTrack();
if (track.GetEvent()) std::cout << track.GetEnergy() << " " << track.GetLength() << std::endl;
