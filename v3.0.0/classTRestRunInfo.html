Detailed Description

Description of a run: numbers, tags, runInfo, times and entries, without anything of the processing (files, input format...). TRestRun is a TRestRunInfo plus the processing; the runs of a TRestDataSet are TRestRunInfo (built from the TRestRun stored in the run files, no file opened).

Its keys are part of the TRestRun section of a configuration:

run:
class: TRestRun
runNumber: 123
subRunNumber: 0
runType: calibration
runUser: rest
runTag: AlphaCAMM
runDescription: Calibration with an Am-241 source
experimentName: AlphaCAMM
runInfo:
meshVoltage: 300 V
driftVoltage: 1000 V
# mergedSubRuns, startTime, endTime and entriesSaved are written by REST
