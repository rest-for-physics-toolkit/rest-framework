Detailed Description

Selection of the entries of a dataset in the range of an observable holding a quantile interval of the signal (the reference), e.g. the 80% of a calibration with the lowest log odds. See the class documentation in TRestDataSetSignalSelection.cxx.

Author
JuanAn García juana.nosp@m.ngp@.nosp@m.uniza.nosp@m.r.es

Selection of signal-like entries, a process of TRestDataSetProcessManager. The range of an observable between two quantiles of its distribution in the reference (the signal, e.g. a calibration: referenceFileName with the cuts, see TRestDataSetProcess) is computed, and only the entries of the dataset processed (e.g. a background) that pass the same cuts and have the observable in that range are kept: the signal efficiency is fixed, within the cuts (e.g. an energy window and a fiducial region), and applied to the background. The kept entries of each run are its selectedEntries in the output dataset.

The observable is any column, e.g. the log odds of TRestDataSetLogOdds (logOdds_total, lower values for the signal) or the score of TRestDataSetTMVA (bdt_score, higher values for the signal); the quantiles tell which part of the signal is kept:

  • [0, 0.8]: the 80% of the signal with the lowest values (observable <= max), e.g. log odds.
  • [0.2, 1]: the 80% with the highest values (observable >= min), e.g. the score of a BDT.
  • [0.1, 0.9]: the central 80% (min <= observable <= max).

Parameters

  • observable: column of the datasets.
  • quantiles: [lower, upper] quantiles of the reference kept, 0 <= lower < upper <= 1 (0 and 1: no limit on that side). The efficiency is upper - lower (up to ties of the values).
  • referenceFileName, cuts: the signal, see TRestDataSetProcess. The cuts are also applied to the dataset processed.

Results

  • range: [min, max] of the observable kept (-.inf and .inf: no limit on that side).
  • efficiency: fraction of the reference in the range.
  • referenceUsed, parametersFileName: see TRestDataSetProcess.

Example (in a TRestDataSetProcessManager, the energy and fiducial cuts defined in the manager):

bdtSelection: class: "TRestDataSetSignalSelection" referenceFileName: "Dataset_Calibration_TMVA.root" cuts: ["energy", "fiducial"] observable: "bdt_score" quantiles: [0.2, 1]
