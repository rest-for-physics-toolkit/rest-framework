Detailed Description

Computes observables of the tracks of a TRestTrackEvent, for any readout: scalars for the main track (the most energetic one or, with projections, the main tracks of all of them together), vectors for the other tracks and, for the given projections (hit types, e.g. XZ and YZ for strips), the main track of each one and balances. Optionally rejects events by number of tracks.

Author

JuanAn García juana.nosp@m.ngp@.nosp@m.uniza.nosp@m.r.es

Computes observables of the tracks of a TRestTrackEvent, for any readout. The event is not modified.

The type of each track is the type of its hits (TRestHitsData::REST_HitType: XZ = 10, YZ = 15, XYZ = 30, ...). Coordinates a track does not define are NaN (mean, sigma and gaussian sigma).

Track observables (<name>): Energy, NHits; Length (TRestHits::GetTotalDistance) and Volume (squared distance of the farthest hits); MeanX/Y/Z (energy weighted); SigmaX/Y/Z (energy weighted size, TRestHits::GetSigmaX, ...); GaussSigmaX/Y/Z (gaussian fit, TRestHitsAnalysis::GetGaussSigma, gaussian integrated over each strip, centre and sigma fitted; only with gaussFit: true, otherwise 0; -1 without result, e.g. a single position); Twist, TwistWeighted (TRestHitsAnalysis::GetTwist, GetTwistWeighted) and TwistLow, TwistHigh (lowest and highest twist of the first and last twistTailPercentage% of the hits); Size and MaxNodeSize: sum and maximum of the node sizes, sqrt(sigmaX² + sigmaY² + sigmaZ²) of the coordinates the node defines (the sigmas given by TRestTrackReductionProcess; 0 for tracks not reduced).

Observables:

  • NTracks, TotalEnergy.
  • MaxTrack<name>: the main track. Without projections, the most energetic track, whatever its type (all the track observables). With projections, the hits of the main track of every projection together, as legacy for the most energetic X and Y tracks (MaxTrackEnergy, MaxTrack_XYZ_...): MaxTrackEnergy, MaxTrackNHits and MaxTrackMean, MaxTrackSigma, MaxTrackGaussSigma of the coordinates any projection defines (X, Y and Z for XZ and YZ), each one from the hits that define it; length, twists and sizes are those of MaxTrack_P_<name>.
  • MaxTrackEnergyRatio: (TotalEnergy - MaxTrackEnergy) / TotalEnergy; MaxTrackSkewXY, MaxTrackSkewZ (TRestHits::GetSkewXY, GetSkewZ).
  • Tracks<name>: vectors with the tracks out of the main track (with projections, those that are not the main track of any projection), in decreasing energy, and TracksType with the type of each one.

For each projection P in projections (hit types, e.g. [XZ, YZ] for strip readouts, which give X and Y tracks):

  • NTracks_P, MaxTrack_P_<name>: number of tracks of type P and main track of type P (Mean, Sigma and GaussSigma only along the coordinates P defines, e.g. X and Z for XZ); MaxTrack_P_EnergyRatio: (E_P - MaxTrack_P_Energy) / E_P, with E_P the energy of the tracks of type P.
  • For each pair P1, P2 (in the given order): EnergyBalance_P1_P2 and SigmaBalance_P1_P2, as (a - b) / (a + b) of the energies and of the sigmas of the coordinate only each one defines (X of XZ and Y of YZ; NaN if there is not exactly one). 0 if a + b = 0.

projections lists the hit types the readout gives: [XZ, YZ] for strips, [XYZ] for a 3D readout (only needed together for a readout giving both). Legacy summed the X, Y and XYZ tracks to cover both cases at once, the terms of the types the readout does not give being 0.

Legacy observables for strips with projections [XZ, YZ]: nTracks_X/Y = NTracks_XZ/YZ, MaxTrackEnergy, MaxTrackEnergyRatio as legacy, MaxTrack_XZ_nHits = MaxTrack_XZ_NHits, MaxTrack_XYZ_SigmaZ2 = MaxTrackSigmaZ^2, MaxTrack_XYZ_GaussSigmaZ = MaxTrackGaussSigmaZ, MaxTrack_XYZ_skewXY/Z = MaxTrackSkewXY/Z, MaxTrackEnergyBalanceXY = EnergyBalance_XZ_YZ, MaxTrackxySigmaBalance = SigmaBalance_XZ_YZ.

With cutsEnabled, events are rejected before the analysis when the number of tracks of any projection (NTracks_P) is out of nTracksCut; without projections the cut applies to the total NTracks. Legacy nTracksXCut/nTracksYCut correspond to nTracksCut with projections [XZ, YZ] (a single range for both). With a minimum of 1 the events with no tracks in a projection are rejected; without the cut, the coordinates only that projection defines are NaN in MaxTrack<name>.

Example (strip readout):

trackAnalysis: class: "TRestTrackAnalysisProcess" projections: ["XZ", "YZ"] observables:

  • "NTracks_XZ"
  • "NTracks_YZ"
  • "MaxTrackEnergyRatio"
  • "MaxTrack_XZ_NHits"
  • "MaxTrack_YZ_NHits"
  • "MaxTrackSigmaZ"
  • "EnergyBalance_XZ_YZ"
  • "SigmaBalance_XZ_YZ"

Migrated from the legacy track library (Javier Galan), redesigned to be readout independent: the legacy observables of the most energetic X, Y and XYZ tracks are given by the projections. The time observables (EventTimeDelay, MeanRate_InHz) are not track observables and are not included.

Also replaces legacy TRestTrackPointLikeAnalysisProcess (after TRestTrackReductionProcess, without projections): nTracks → NTracks, totalEnergy → TotalEnergy, nTotalHits → MaxTrackNHits + Sum(TracksNHits), clusterEnergyBalance → 1 - MaxTrackEnergyRatio, size → MaxTrackSize, sizeBalance → MaxTrackMaxNodeSize / MaxTrackSize; clusterLengthBalance and hitsBalance (of the longest track and the track with most hits, not the main one) → Max(MaxTrackLength, Max(TracksLength)) / (MaxTrackLength + Sum(TracksLength)), and the same with NHits (legacy hitsBalance was an integer division).
