TCanvas * REST_Garfield_DrawMedium ( const std::string &  fileName,
std::string  medium = "",
double  pressure = 0 
)

Draws the tables of a medium file generated by restGarfield:

  • transport tables (TRestDetectorTransportTable): drift velocity, longitudinal and transversal diffusion, Townsend and attachment coefficients versus the electric field, one color per table (pressure, temperature and field range) and one line style per carrier. Drawn at the pressure of each table or, if pressure (bar) > 0, all scaled to that pressure as TRestDetectorMedium does (E/p): tables computed at different pressures then overlap if the scaling holds;

  • gain tables (TRestDetectorGainTable): mean gain and Polya theta versus the amplification field, one color per table. The distributions of the avalanche sizes are the TH1D of amplification/<medium>/<key>/ in the file.

    restRoot REST_Garfield_DrawMedium("~/.rest/media/ArIso.root")

    REST_Garfield_DrawMedium("~/.rest/media/ArIso.root", "", 1.4) // transport scaled to 1.4 bar

Parameters
fileNameMedium file (~ is expanded to HOME).
mediumName of the medium in the file; by default the file name without extension.
pressurePressure (bar) to which the transport tables are scaled; 0 draws each table at its own pressure.
Returns
The canvas (3x3 pads), or nullptr if the file cannot be opened or has no tables of the medium.
