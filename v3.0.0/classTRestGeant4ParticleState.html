Detailed Description

Stores one primary/secondary particle state used by generators and track metadata.

A primary particle given by TRestGeant4PrimaryGenerator to restG4: name, excitation level and charge (ions), kinetic energy (keV), unit direction, origin (mm) and start time (us).
