Detailed Description

Particle names and IDs of REST: the ID of a particle is its PDG encoding (Monte Carlo particle numbering scheme, as Geant4 GetPDGEncoding), the one stored in the events (e.g. the tracks of TRestGeant4Event, the hits of TRestDetectorHitsEvent; 0 = unknown). The names are those of Geant4 (fixed here, so a configuration means the same with any Geant4 version):

  • a table of the usual particles: gamma, e-, e+, mu-, mu+, tau-, tau+, the neutrinos (nu_e, anti_nu_e...), pi+, pi-, pi0, kaon+, kaon-, kaon0, anti_kaon0, kaon0L, kaon0S, proton, anti_proton, neutron, anti_neutron, lambda and the light nuclei deuteron, triton, He3 and alpha;
  • the other nuclei as element symbol and mass number, e.g. Ar40 (PDG 100ZZZAAAI: 1000180400). A Geant4 excitation energy in brackets is accepted (Ar40[1460.859]: level I = 9, an excited state);
  • a number is taken as a PDG encoding.

The exact names of the particles of a simulation (excited states with their energy) are those stored by restG4 in TRestGeant4PhysicsInfo, which falls back to these functions.
