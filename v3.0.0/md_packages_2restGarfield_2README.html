The restGarfield package

This package is used to compute with Garfield++ the transport and gain properties of the detector media, stored in tables that the detector library reads without depending on Garfield++.

Optional application that computes with Garfield++ the transport and gain tables of a medium defined in a TRestDetectorTransportManager YAML configuration, and stores them in the medium file (mediumFile of the TRestDetectorMedium, by default <name>.root). The REST libraries do not depend on Garfield++: the tables are read by TRestDetectorMedium (detector library).

  • Transport tables (TRestDetectorTransportTable): drift velocity, longitudinal and transversal diffusion, Townsend and attachment coefficients versus the electric field, for electrons, holes and ions (the carriers available in the Garfield medium). Gases use Magboltz (MediumMagboltz, up to 6 components); solids of a single component Si, GaAs, GaN, CdTe or diamond use the Garfield solid media.
  • Gain tables (TRestDetectorGainTable, gases only): mean gain, Polya theta and the avalanche size distributions, from microscopic avalanches of one electron in a uniform field across a gap (parallel plates).
  • Drift responses in field maps (TRestDetectorDriftResponse, gases only, special simulations with a non-uniform drift field): electrons drifted with AvalancheMC from the nodes of a grid, in a field map exported by CST Studio Suite, to a plane above the readout (the start of the amplification), with the gas of a transport table of the medium file; per node the arrived fraction and the histograms of the displacement on the readout plane and of the drift time. Each response goes to its own responseFile, read by TRestDetectorHitsDriftResponseProcess (detector library) instead of TRestDetectorHitsDriftProcess.

Tables already in the medium file, and response files that exist, are skipped unless overwrite: true.

Build

CMake option REST_GARFIELD (default ON). It needs Garfield++ (found with GARFIELD_INSTALL or GARFIELD_HOME) and the detector library; otherwise the package is skipped with a message.

cmake -DREST_GARFIELD=ON ..

Usage

restGarfield <config.yaml> [--set name=value ...] [--jobs N]
restGarfield --version

--version prints the version of the code, also printed at the start; each table keeps in its generator (entry of the table in the metadata of the medium file) the configuration used, the program, the date and the code (version, commit and clean state of restGarfield).

--set overrides a parameter of the parameters section for this execution (repeatable). --jobs N splits the field nodes of each gas transport table in up to N processes, each computing a contiguous part of the grid of at least 2 nodes (Magboltz is not thread safe, so processes instead of threads); the table is the same. Several media can also run at once as separate restGarfield processes, even writing to the same medium file (e.g. Ar99_iC4H10_1, Ar98_iC4H10_2... in ArIso.root, each one in tables/<medium>/): the file is locked while it is read or written. Example based on examples/ArIso.yaml (installed in examples/restGarfield; its gain and drift sections are commented out there):

transportManager:
class: "TRestDetectorTransportManager"
medium:
class: "TRestDetectorMedium"
name: "ArIso"
state: "gas"
components: {Ar: 99, iC4H10: 1}
transport:
temperatures: [293.15]
fieldRange: [30 V/cm, 500 V/cm]
fieldNodes: 30
gain:
gap: 50 um
reducedFieldRange: [50 kV/cm/bar, 70 kV/cm/bar]

Configuration keys

TRestDetectorTransportManager: medium (a TRestDetectorMedium), transport, gain and drift (each a map or a list of maps, one per set of tables or response). The drift responses are computed after the tables, so the transport table they use can be computed in the same run.

transport:

Key Default Description
pressure 1 bar Pressure of the tables (gas tables are scaled to other pressures with E/p).
temperatures medium temperature One table per temperature (K).
fieldRange [10 V/cm, 1000 V/cm] Electric field range.
fieldNodes 20 Number of field nodes.
logField true Logarithmic field spacing.
nCollisions 10 Magboltz collisions (x 10^7).
maxElectronEnergy 400 eV Maximum electron energy in Magboltz.
usePenning false Penning transfer in the Townsend coefficient (gases).
penningRate 0 Penning transfer probability, (0, 1].
overwrite false Compute again the tables already in the file.

gain:

Key Default Description
gap (required) Amplification gap.
pressures medium pressure One set of tables per pressure.
temperatures medium temperature One table per temperature (K).
reducedFieldRange (required) Reduced field range E/p; the fields are E = (E/p) * p.
fieldNodes 5 Number of equally spaced field nodes.
avalanches 1000 Avalanches (one primary electron each) per field node.
usePenning false Penning transfer.
penningRate 0 Penning transfer probability.
overwrite false Compute again the tables already in the file.

drift (lengths in mm unless a unit is given):

Key Default Description
fieldMap (required) ASCII export of the electric field by CST (header x [mm] y [mm] z [mm] Ex [V/m] Ey [V/m] Ez [V/m], the units read from it; x fastest).
fieldMapOffset [0, 0, 0] Position of the origin of the CST frame in the detector frame.
readouts (required) YAML file with the TRestDetectorReadoutManager of the readout (distance and normal; the normal must be along x, y or z).
readout data readout Name of the readout in the manager.
boundary 0 Distance from the readout to the plane where the drift ends (above the mesh); the field map must reach above it.
transportTable the only one Key of the transport table of the medium file (the gas at the pressure of the medium).
xRange, yRange, zRange (required) Grid of start points (detector frame).
gridNodes [2, 2, 2] Nodes of the grid along x, y and z (at least 2 each).
electrons 1000 Electrons drifted from each node.
stepSize 1 mm Distance step of AvalancheMC.
positionBins 20 Bins per axis of the displacement histogram of each node.
timeBins 20 Bins of the drift time histogram of each node.
responseFile (required) Output file of the response.
overwrite false Compute the response again if the file exists.

The drift of the nodes is not split in processes (--jobs applies to the transport tables only).

See the TRestDetectorTransportManager, TRestDetectorMedium and TRestDetectorDriftResponse documentation for the validation of these keys.

Macros

  • REST_Garfield_DrawMedium(fileName, medium = "", pressure = 0): draws the transport tables (versus E, one color per table, one line style per carrier; scaled to pressure in bar if > 0) and the gain tables (mean gain and Polya theta) of a medium file.
restRoot
root [0] REST_Garfield_DrawMedium("ArIso.root")
root [1] REST_Garfield_DrawMedium("ArIso.root", "", 1.4)

Tests

With BUILD_TESTING (test/, ctest label restGarfield): the Garfield++ gas of a medium and the transport and gain tables computed with small grids (a silicon table, a gas table with one Magboltz collision in two processes, a gain table of a few avalanches at a low field), written to medium files of the build directory and read back; a small CST field map, the Garfield++ gas of a transport table and the drift response in a uniform field map (straight drift to the boundary plane at the drift velocity of the table). The suites *Long (the transport table in two processes) are skipped with ctest -L restGarfield -E Long.
