Detailed Description

Log odds of observables with respect to their PDFs in a reference dataset: log(1 - p) - log(p) of each observable and their sum. See the class documentation in TRestDataSetLogOdds.cxx.

Author
JuanAn García juana.nosp@m.ngp@.nosp@m.uniza.nosp@m.r.es

Log odds of observables, a process of TRestDataSetProcessManager. The probability density function (PDF) of each observable is built in the reference (referenceFileName with the cuts, see TRestDataSetProcess), a histogram in its range normalized to 1; for each entry of the dataset, with p the probability of the bin of its value, the column <name>_<observable> = log(1 - p) - log(p) is added (1000 if p is 0, e.g. outside the range, and -1000 if p is 1, a single bin with entries), and <name>_total with their sum. The lower the value, the more likely the entry is in the distribution of the reference.

Parameters

  • observables: list of observable (column), range of the PDF and nBins (100).
  • referenceFileName, cuts: see TRestDataSetProcess.

Results

  • observables: pdf, the probability of each bin.
  • referenceUsed, parametersFileName: see TRestDataSetProcess.

Objects (folder RESTDataSetStore/TRestDataSetLogOdds/<name> of the output dataset): the PDF of each observable, pdf_<observable>.

Example (in a TRestDataSetProcessManager, the energy cut defined in the manager):

odds: class: "TRestDataSetLogOdds" referenceFileName: "Dataset_Calibration_Calibrated.root" cuts: ["energy"] observables:

  • {observable: "trackAnalysis_MaxTrack_XYZ_SigmaZ2", range: [0, 20], nBins: 100}
  • {observable: "trackAnalysis_MaxTrackEnergyBalanceXY", range: [-5, 5], nBins: 100}

Differences with legacy (TRestDataSetOdds): a process of a dataset pipeline (no ComputeLogOdds nor dataSetName/outputFileName); oddsFile replaced by referenceFileName (a dataset processed by this process reuses its PDFs, stored in its configuration, otherwise they are built); the cut is TRestCut of the manager by name (cuts) instead of a TRestCut inside; observables with observable instead of the observable elements with name.
