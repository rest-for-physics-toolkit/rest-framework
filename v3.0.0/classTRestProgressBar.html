Detailed Description

Console progress bar with the count, the estimated time left (ETA, minutes) and the percentage, redrawn in place on std::cout, e.g. 120 Events, 1.5 min ETA, 12.0%[===> ]. Not thread safe: it is updated by one thread (the global instance RESTProgress is used by the executables).
