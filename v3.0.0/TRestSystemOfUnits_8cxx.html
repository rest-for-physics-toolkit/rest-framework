namespace  REST_Units
 System of units of REST: the values are stored in the REST units keV, us, mm, kg, V, T, bar, rad and MHz (1/us), and the configuration gives them with units ("300 V", "1 kV/cm", "5.9 keV", "100 kHz"), converted with ParseUnit and ParseValueWithUnits (TRestWithUnits for the configuration fields).
