Detailed Description

A number read from the configuration with optional units, e.g. energy: "5.9 keV" or voltage: 300, stored in REST units (REST_Units::ParseValueWithUnits); it converts to and from double. The YAML written back (UpdateYAMLFromParams) is the plain number in REST units. Reading a text that is not a number with valid units throws (YAML::TypedBadConversion).
