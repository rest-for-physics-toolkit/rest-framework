Detailed Description

The generator section of TRestGeant4Metadata: the spatial generator (its type selects a TRestGeant4SpatialGenerator, which reads its fields from this same section), the optional spatialDensityFunction and the source (one or a list of TRestGeant4ParticleSource; none for the cry generator, which gives the particles). Each part is configured with UpdateParamsFromYAML and written back with UpdateYAMLFromParams, so the stored YAML has the values used (e.g. the cosmic radius). The options are documented in TRestGeant4PrimaryGenerator, which samples the primaries. 

generator:
  type: "point"                  # point, volume, surface, cosmic or cry
  position: [0, 0, -200 mm]
  source:
    particle: "e-"
    angular:
      type: "flux"
      direction: [0, 0, 1]
    energy:
      type: "mono"
      energy: 30 keV
