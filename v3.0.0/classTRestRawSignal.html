Detailed Description

Non-owning view over one signal stored inside TRestRawSignalData.

Obtained with TRestRawSignalEvent::GetSignal or GetSignalByID. The view is invalidated when signals are added to or removed from the event. Bin indices are not checked.

◆ IsADCSaturation()

bool TRestRawSignal::IsADCSaturation ( int  nFlat = 3) const
inline

Returns true if the raw waveform shows an ADC saturation flat top.

Legacy criterion (TRestRawSignal::IsADCSaturation): the first bin holding the maximum raw value and the following bins, nFlat in total, all have that same maximum value. It does not depend on the ADC range, so it works for 12-bit data and for simulated signals with any maximum value.
