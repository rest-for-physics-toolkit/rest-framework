Detailed Description

Event container holding a flat list of 3D hits (position + energy + time + type + particle).

The hits are stored in a TRestHitsData (one vector per quantity, stored as float) and accessed through a TRestHits view (GetHits), which provides the hit analysis methods (mean position, sigma, skewness...). The type of each hit (TRestHitsData::REST_HitType: X, Y, XY, XZ, YZ, XYZ...) tells which coordinates it defines (e.g. XZ and YZ for the hits of strip readouts; the others are NaN).

The particle of each hit (fHitParticleID) is the Particle ID (PDG encoding) of the Geant4 track that produced it, set by TRestGeant4ToDetectorHitsProcess and kept by the hits processes (e.g. for the scintillation profile of each particle); 0 when it is not known (real data, hits from signals).

Branches of the event tree: fHitX, fHitY, fHitZ, fHitTime, fHitEnergy, fHitType and fHitParticleID (plus those of TRestEvent). It is the input and output of the hits processes of this library (drift, avalanche, smearing, transformation, light attenuation, analysis) and the output of TRestDetectorSignalToHitsProcess and of TRestGeant4ToDetectorHitsProcess (connectors library).
