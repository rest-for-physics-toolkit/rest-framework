Detailed Description

An entry of activeVolumes: the hits of the active volumes are stored. Since only active volumes can be sensitive, the sensitive ones are flagged here (there is no sensitiveVolumes list): 

activeVolumes:
  - name: "gas"          # regular expression of physical (or logical) volume names
    chance: 1.0          # probability to store the hits of an event in the volume
    maxStep: 10 um       # Geant4 maximum step in the volume (0: no limit)
    sensitive: true      # an event is stored only with energy in a sensitive volume

chance (0 to 1, default 1): restG4 draws, for each Geant4 event, whether the hits in the volume are stored (the same for all its sub-events); when not, the volume is as a non active one for that event (e.g. chance: 0.1 in a vessel stores its hits in 10% of the events, to save space). The sensitive energy, which decides if the event is stored, is not affected.
