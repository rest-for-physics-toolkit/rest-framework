Detailed Description

Process of a TRestDataSetProcessManager: computes its parameters from a reference dataset (e.g. the calibration line from the peaks of a calibration) and adds columns to the dataset processed with them.

A process works in two steps, called by the manager for each dataset:

  1. ObtainParameters: the parameters (results, registered fields) are read from the reference if it was processed by this process, otherwise computed on it (ComputeParameters, implemented by each process: peak fits in TRestDataSetCalibration and TRestDataSetGainMap, PDFs in TRestDataSetLogOdds). The reference is only read, its columns are not changed.
  2. Apply: the columns computed with the parameters are added to the dataset processed (e.g. the calibrated energy of a background with the parameters of a calibration).

Parameters common to all the dataset processes:

  • referenceFileName: dataset where the parameters are computed, used as it is (the previous processes of the pipeline are not applied to it). Empty: the dataset processed, with the columns of the previous processes. A pattern (* and ?) must match a single dataset, unless referenceSelection is given. restManager --r <process>=<file> sets it.
  • referenceSelection: how a dataset is chosen among those matching referenceFileName: "closest" in time to the dataset processed (the smallest gap between their start and end times, 0 if they overlap; then the closest middle times), e.g. the calibration taken nearest to a background. Empty (default): a single match.
  • cuts: names of the TRestCut (defined in the manager) applied to the reference.

If the reference has in its metadata a process with the same name and class (a dataset processed by it), its stored configuration, with its results, is used and nothing is computed.

Results:

  • referenceUsed: the dataset used as reference (chosen by referenceSelection).
  • parametersFileName: the dataset where the parameters were computed. The same as referenceUsed unless they were read from it: then the one where they were originally computed (stored with them), e.g. a background B with a calibration A as reference, A processed with the parameters computed on C: referenceUsed is A and parametersFileName is C.

The objects of a process (spectra, fits, PDFs) are in the folder RESTDataSetStore/<class>/<name> of the dataset (e.g. RESTDataSetStore/TRestDataSetCalibration/calib), its configuration with the results in RESTMetadataStore as any metadata.

calib:
class: TRestDataSetCalibration # a derived class, with its own keys
referenceFileName: "Dataset_Calibration_*.root"
referenceSelection: closest
cuts: ["energy"]
# referenceUsed and parametersFileName are results, written by REST
