Garfield++ gas whose transport tables are those of a TRestDetectorTransportTable (e.g. read from the medium file), without running Magboltz: for the drift of electrons and ions with AvalancheMC or DriftLineRKF in a field map. Only the tables are set (no cross sections: not for AvalancheMicroscopic).

The tables are those of table at pressure, scaled as TRestDetectorTransportTable does (E/p): its field nodes at that pressure. The Garfield gas keeps its default pressure, the pressure of its tables, so Garfield does not scale them again. The electron velocity, diffusion, Townsend and attachment coefficients are set (Garfield keeps the logarithm of the coefficients, -30 for 0), and the ion mobility and diffusion if the table has ions. Units: field V/cm, velocity cm/ns, diffusion sqrt(cm), coefficients 1/cm, mobility cm2/(V ns).

Parameters
mediumGas medium definition of the table (its components name the Garfield gas).
tableTransport table with electrons.
pressurePressure in bar.
Returns
The Garfield gas, owned by the caller.
Exceptions
std::runtime_errorif the medium is not a gas, its components are not valid for Garfield, or the table has no electrons.

void RunTransportSimulation ( const TRestDetectorMedium &  medium,
TRestDetectorTransportTable &  simulation,
bool  verbose,
int  jobs = 1

Computes the tables of a TRestDetectorTransportTable configuration with Garfield++: for each condition, creates the Garfield medium of the type of the medium definition (MediumMagboltz, which computes the gas table with Magboltz, MediumSilicon, ...), evaluates the transport parameters on the field grid and adds the table to the medium file (TRestDetectorTransportTable).

One table per temperature (by default the one of the medium) at the pressure of the configuration. Only the carriers (electron, hole, ion) that the Garfield medium provides are stored; electrons are required. A table already in the medium file is skipped unless overwrite is set.

Parameters
mediumMedium definition: a gas, or a solid of a single component Si, GaAs, GaN, CdTe or diamond. Its mediumFile receives the tables.
simulationConfiguration of the transport tables (the transport section of TRestDetectorTransportManager).
verboseVerbose Magboltz gas table generation (GenerateGasTable).
jobsGases: the field nodes are split in up to jobs processes (Magboltz is not thread safe), each one computing a contiguous part of the grid (at least 2 nodes); the table is the same.
Exceptions
std::runtime_errorif the medium is not supported, usePenning is set for a non-gas, there is no electron transport or the medium file cannot be opened.
