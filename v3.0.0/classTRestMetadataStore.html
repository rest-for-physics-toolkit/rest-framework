Detailed Description

The metadata stored in a REST file (RESTMetadataStore), created as objects: used by TRestRun and TRestDataSet to give access to the metadata of their file (e.g. a readout or a TRestGeant4Metadata with its geometry).

Each metadata is created with MetadataClassRegistry (its class must be registered: its library loaded, as in restRoot and restManager) from its stored configuration, not checked, and loads its objects from the file (TRestMetadata::LoadFromFile, e.g. the readouts and geometries). A metadata that cannot be created is skipped with an error message.
