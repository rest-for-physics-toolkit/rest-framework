Imports a readout (any TRestDetectorReadout, e.g. the TRestGDMLReadout of the vetoes) from a ROOT file written by REST_Detector_GenerateGDMLReadout, prints it, tests the position lookup (GetChannelFromPosition at a fixed point, GetPositionFromChannel of the DAQ channels 289 to 292) and draws the geometry with those channels highlighted (ViewActiveEvent). Throws if the readout is not in the file; prints an error and returns if the file cannot be opened or the readout or its decoding cannot be imported. The input file is closed after the import.
