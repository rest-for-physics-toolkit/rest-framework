Detailed Description

Generic event viewer: draws the current event (TRestEvent::DrawEvent with the plot option of the browser) in a canvas embedded in TRestBrowser.

Derived viewers (e.g. 3D viewers based on TRestEveEventViewer) override AddEvent and Plot. They are created by TRestBrowser from their class name (ROOT dictionary) or given to it already created.
