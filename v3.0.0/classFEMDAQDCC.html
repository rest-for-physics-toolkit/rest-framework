Detailed Description

Data taking of a DCC (the first FEM of the configuration, with its FECs).

The acquisition is driven by the commands of startDAQ (no receiver thread): for each event it starts the SCA, waits for the trigger and requests the data of each ASIC of the FECs (areq); the data packets go to FEMProxy::tmpBuffer followed by an end-of-event mark (0xFFFF) and a 48-bit timestamp (10 ns ticks since the start of the run, taken by the computer), which the event builder decodes.
