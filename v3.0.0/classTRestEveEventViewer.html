Detailed Description

Base of the 3D event viewers built on ROOT Eve (TEveManager): a single 3D view, a multi view (3D, R-Phi and Rho-Z projections) and orthogonal XY, XZ and YZ projections, with the geometry and the energy deposits of the event as points.

Derived classes implement AddEvent, adding the hits of their event with AddSphericalHit and calling Update. The Eve windows are created in the constructor (Initialize), not embedded in TRestBrowser.
