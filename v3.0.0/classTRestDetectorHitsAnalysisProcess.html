Detailed Description

Computes observables of the hits of a TRestDetectorHitsEvent, for any readout: energy, number of hits, energy weighted mean, sigma and skewness, and per projection (hit type) with balances.

The parameters (YAML keys), the observables and an example are described in the class documentation (TRestDetectorHitsAnalysisProcess.cxx).

Author
Javier Galán javie.nosp@m.r.ga.nosp@m.lan@u.nosp@m.niza.nosp@m.r.es
JuanAn García juana.nosp@m.ngp@.nosp@m.uniza.nosp@m.r.es

Computes observables of the hits of a TRestDetectorHitsEvent, for any readout. The event is not modified; events without hits are rejected.

The type of each hit (TRestHitsData::REST_HitType: XZ = 10, YZ = 15, XYZ = 30, ...) gives the coordinates it defines; each coordinate observable uses the hits that define it, and is NaN if no hit defines it.

Observables:

  • NHits, Energy; MaxHitEnergy, MinHitEnergy, MeanHitEnergy.
  • MeanX/Y/Z: energy weighted mean position; SigmaX/Y/Z: energy weighted size (TRestHits::GetSigmaX, ...); SkewXY, SkewZ: skewness (TRestHits::GetSkewXY, GetSkewZ).
  • GaussSigmaX/Y/Z: size from a gaussian fit of the energy against the coordinate, with the hits that define it (TRestHitsAnalysis::GetGaussSigma: gaussian integrated over each strip, centre and sigma fitted); only with gaussFit: true (not registered otherwise); -1 without result (e.g. a single position), NaN if no hit defines the coordinate.
  • FiducialEnergy: energy of the hits inside the fiducial cylinder (fiducialCenter, fiducialAxis, fiducialRadius, fiducialLength); only with fiducialRadius (not registered otherwise). The coordinates a hit does not define take the value of the center: with the axis along X, Y or Z, a hit (e.g. XZ) is inside if some value of them is (XZ with axis Z: |X - centerX| <= radius).

For each projection P in projections (hit types, e.g. [XZ, YZ] for strip readouts):

  • NHits_P, Energy_P: number of hits and energy of type P.
  • For each pair P1, P2 (in the given order): NHitsBalance_P1_P2, EnergyBalance_P1_P2 and SigmaBalance_P1_P2, as (a - b) / (a + b) of the number of hits, the energies and the sigmas of the coordinate only each one defines (X of XZ and Y of YZ, from the hits of each type; NaN if there is not exactly one). 0 if a + b = 0.

Legacy observables (strips with projections [XZ, YZ]): nHits → NHits, nHitsX/Y → NHits_XZ/YZ, balanceXYnHits → NHitsBalance_XZ_YZ, energy → Energy, energyX/Y → Energy_XZ/YZ (legacy: the hits defining X or Y, also XYZ), balanceXYenergy → EnergyBalance_XZ_YZ, maxHitEnergy, minHitEnergy and meanHitEnergy → MaxHitEnergy, MinHitEnergy, MeanHitEnergy, xMean → MeanX, xSigma → SigmaX, xy2Sigma → SigmaX² + SigmaY², z2Sigma → SigmaZ², xySigmaBalance → SigmaBalance_XZ_YZ, xySkew → SkewXY, zSkew → SkewZ. Removed: nHitsSizeXY (sqrt(NHits_XZ² + NHits_YZ²)), meanHitEnergyBalance (1 / NHits) and the fiducial cylinder and prism observables (see below).

Parameters:

  • projections: see above (default none).
  • gaussFit: compute GaussSigmaX/Y/Z (default false).
  • fiducialCenter: center of the fiducial cylinder (default [0, 0, 0] mm).
  • fiducialAxis: direction of its axis, any length (default [0, 0, 1]).
  • fiducialRadius: its radius, 0 for none (default 0 mm).
  • fiducialLength: its length along the axis, centered on the center, 0 for infinite (default 0 mm).

Example (strip readout):

hitsAnalysis: class: "TRestDetectorHitsAnalysisProcess" projections: ["XZ", "YZ"] observables:

  • "Energy"
  • "NHits_XZ"
  • "NHits_YZ"
  • "EnergyBalance_XZ_YZ"
  • "SigmaZ"

Migrated from the legacy detector library (Javier Galan), redesigned to be readout independent: the legacy X and Y observables are given by the projections. Veto hits are not excluded (there is no veto hit type, veto hits go in their own pipeline). The fiducial cylinder and prism (cylinderFiducialization, prismFiducialization) are not migrated: they only worked with XYZ hits (simulations, where TRestDetectorHitsToSignalProcess already rejects the hits out of the drift volume or the readout), and the selection of events by position is a TRestCut on MeanX/Y/Z, e.g. MeanX * MeanX + MeanY * MeanY < 2500.

Also replaces legacy TRestDetectorHitsGaussAnalysisProcess (gaussFit: true): xSigmaGaus → GaussSigmaX (legacy: all the hits, here those defining X), xy2SigmaGaus → GaussSigmaX² + GaussSigmaY², xySigmaBalanceGaus → (GaussSigmaX - GaussSigmaY) / (GaussSigmaX + GaussSigmaY) (legacy: -1 if a fit failed). And legacy TRestDetectorHitsReadoutAnalysisProcess, which took the hits of one channel type of the readout (veto hits go in their own pipeline here): readoutEnergy → Energy, readoutNumberOfHits → NHits, readoutAveragePositionX → MeanX, readoutSigmaPositionX → SigmaX, readoutSigmaPositionXY → sqrt(SigmaX² + SigmaY²), readoutSigmaPositionXYBalance → (SigmaX - SigmaY) / (SigmaX + SigmaY), readoutSkewnessPositionXY → SkewXY, readoutEnergyInFiducial → FiducialEnergy (fiducialPosition → fiducialCenter, fiducialDiameter → 2 fiducialRadius, legacy: a circle in XY, fiducialAxis [0, 0, 1]), removeZeroEnergyEvents → TRestCut on Energy > 0. Not migrated: readoutSkewnessPositionX/Y/Z and ignoreZ (only for the readout channel lookup).
