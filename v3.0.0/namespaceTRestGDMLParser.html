Detailed Description

GDML geometries as REST reads them (restG4, TRestGeant4GeometryInfo, TRestGDMLReadout, REST_Geant4_ViewGeometry): with the entities expanded and the parameters of the configuration (TRestYAMLUtils::GetParameters) replacing the GDML constants and entities with their name, so a GDML keeps its default values and stays valid for any viewer (no environment variables in it).

GDML with its entities and parameters resolved, in a single text without dependencies:

  • the entities of the DOCTYPE (<!ENTITY name SYSTEM "file"> and <!ENTITY name "text">, also those of the files included) replace their references (&name;), recursively: the files relative to the one that includes them, the URLs (http, https) downloaded (TRestTools::DownloadFile); the DOCTYPE is removed;
  • a parameter (parameters, name -> value) with the name of a text entity replaces its text, and one with the name of a <constant> or <variable> its value: a number in REST units (e.g. "5 um" as 0.005, mm; "1.5 bar" as 1.5), an error if it is not a number. The names of the parameters applied are added to applied if given. The GDML keeps its default values for the parameters not given, so it is a valid GDML that any viewer opens.
