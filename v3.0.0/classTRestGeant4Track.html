Detailed Description

A light view of one track of a TRestGeant4Event (the event and the track index): the data is in the TRestGeant4EventData of the event, so a track is valid only while the event is not modified.

The hit indices of the methods are relative to the track (0 to GetNumberOfHits() - 1). Units: keV, mm, us. The names need the TRestGeant4Metadata of the event (GetGeant4Metadata).
