Adds (or replaces) a decoding of a readout already in a readout file (e.g. one generated by REST_Detector_GenerateReadouts), without rewriting its geometry (TRestDetectorReadout::AddDecoding): to update the decoding of a detector without changing its readout. The physical IDs of the decoding must be among those of the decodings already stored for the readout. A readout manager uses it with its decodingName.

Parameters
readoutFileReadout file, updated.
readoutNameName of the readout in the file (the instanceName of the readout manager).
decodingFileDecoding file (daqChannel physicalID rows).
decodingNameName of the decoding in the file.
Returns
0 on success, 1 on any error; as exit code: restRoot -b -q -e 'gSystem->Exit(<macro>(...));'
