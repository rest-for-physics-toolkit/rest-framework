Detailed Description

Combined canvas of panels (text with run information and observable statistics) and plots (1D and 2D histograms of the analysis tree observables) of one or several files, with TRestCut.

See the class documentation in TRestAnalysisPlot.cxx for all the keys of panels, plots and histograms and the {expressions} of the labels. Short example:

plots:
class: TRestAnalysisPlot
inputFileName: "R*_ANA.root" # empty: the output of the pipeline of the manager
cuts: ["fiducial"]
previewPlot: false
save: "Plots_{run.runTag}.pdf"
outputFileName: "R[runNumber]_plots.root"
paletteStyle: 57
canvasSize: [1200, 600]
canvasDivisions: [2, 1]
canvasDivisionMargins: [0.01, 0.01]
legendPosition: [0.7, 0.75, 0.88, 0.88]
panels:
- labels:
- {text: "Rate: {entries/runLength|%.1f} per hour", position: [0.1, 0.8]}
plots:
- name: "Spectrum"
xLabel: "Energy (ADC)"
variables: [{name: "trackLineAnalysis_Energy", range: [0, 1e6], nBins: 200}]
Author
Gloria Luzón
Javier Galán javie.nosp@m.r.ga.nosp@m.lan@u.nosp@m.niza.nosp@m.r.es
JuanAn García juana.nosp@m.ngp@.nosp@m.uniza.nosp@m.r.es

Combined canvas with the observables of the analysis tree of one or several files (a pattern, e.g. R*_ANA.root): first one pad per panel (text) and then one pad per plot (histograms). The analysis trees are read with an RDataFrame: all the histograms and statistics are filled in a single loop. The input is its inputFileName: a run file, a dataset or a pattern of them (all run files or all datasets), from which a TRestDataSet is generated in memory (TRestDataSet::Generate, nothing written: the same reading of the runs, a run twice or a run file without TRestRun is an error), so the run times and run.key are those of its runs; a manager with only plots has no TRestRun nor TRestDataSet section (restManager --c plots.yaml --i "R*_ANA.root": –i is the inputFileName of every plot). Without inputFileName, TRestManager runs it after the pipeline, on its output file (also the dataset generated or processed by the manager). From restRoot, PlotCombinedCanvas(fileName, manager), or PlotCombinedCanvas(dataSet, manager) with the data frame of a TRestDataSet (e.g. with columns added with Define).

Parameters

  • inputFileName: a run file, a dataset or a pattern of files (e.g. R*_ANA.root). Empty (default): the output of the pipeline of the manager.
  • cuts: names of the TRestCut (defined in the manager) applied to all the data.
  • outputFileName: ROOT file of the combined canvas and the histograms, its own (not the one of the TRestRun); [parameter] of the run (the first run of the input) (e.g. "R[runNumber]_[runTag]_plots.root") and {expressions} are replaced. A data file (with analysis tree, e.g. the output of the pipeline) is updated, keeping its data; otherwise the file is created with the metadata of the manager (the following plots of the same execution update it). Empty (default): not written.
  • save: image of the combined canvas (pdf, png...; {expressions} are replaced, e.g. "Plots_{run.runTag}.pdf"). Empty: not saved.
  • previewPlot: if true the canvas is shown, scaled to fit in the screen, and the files are saved when Enter is pressed (changes to the histograms are kept, changes to the pads are not).
  • canvasSize: size in pixels of the saved files (the preview window keeps its aspect ratio).
  • paletteStyle (57), canvasSize ([800, 600]), canvasDivisions ([2, 2]), canvasDivisionMargins ([0.01, 0.01]), legendPosition ([x1, y1, x2, y2] = [0.7, 0.75, 0.88, 0.88]).

Panels

panels: list of panels, with textSize (0.05), precision (significant digits, 3), cuts (TRestCut names, besides the global ones), enabled (true) and labels: list of text and position ([x, y] in pad coordinates). In the text, each {expression|format} is replaced by its value; the format is optional, printf style (%.2f) or a number of significant digits. In the expression:

  • entries, allEntries (with the global cuts only, e.g. {entries/allEntries} is the fraction of the events that pass the cuts of the panel), runLength (hours, from the start and end time of each run, not affected by the cuts; without them, from the first and last timeSeconds), exposureTime (hours, the real time the simulations represent, not their computing time: TRestRunInfo::fExposureTime of the runs, e.g. of the cosmic rays of restG4, 0 for data), meanRate (Hz), startTime and endTime (dates), cuts (expression of the cuts of the panel);
  • run.key (TRestRunInfo of the first run, e.g. run.runTag, and its runInfo, e.g. run.runInfo.meshVoltage) and instance.key... (any metadata of the first file, e.g. medium.charge.driftField);
  • mean(obs), sigma(obs), min(obs), max(obs): of an observable with the cuts of the panel (only its finite values: NaN, e.g. a line observable not defined, are ignored);
  • any arithmetic of them (TFormula), e.g. {entries/runLength|%.1f}. A single reference to a text (e.g. run.runTag, run.runInfo.meshVoltage: 300 V) is written as it is.

Plots

plots: list of plots, with name, title, xLabel, yLabel, logX/logY/logZ, gridX/gridY, legend, timeDisplay (X axis as dates, e.g. timeSeconds), marginLeft/Right/Top/Bottom, stackOption ("nostack"), normalize (integral of each histogram), scale (each histogram divided by this expression of binSize, entries, integral, runLength and exposureTime, e.g. "binSize*runLength*3600" for a rate), save (file of the pad alone), enabled (true) and histos: list of histograms with

  • name (legend and name in outputFileName; default the plot name for a plot of a single histogram, and plotName_index in histos), option (draw option), cuts (TRestCut names), stats (only for plots of a single histogram), lineColor, lineWidth, lineStyle, fillColor, fillStyle (numbers or names: colors as red or kRed+2 or #rrggbb, line styles solid, dashed, dotted, dashDotted, fill styles as legacy);
  • variables: one (1D) or two (2D, X and Y) of {name, range: [min, max], nBins (100)}; without range (or min >= max) the range is automatic (with timeDisplay, the X axis is the run: from its start to its end time). The name is an observable or an expression of them (C++, as the cuts), e.g. "sqrt(hitsAna_MeanX*hitsAna_MeanX + hitsAna_MeanY*hitsAna_MeanY)" or, for a time with nanoseconds, "timeSeconds + 1e-9*timeNanoSecs". Vector observables fill one entry per element, and can be selected element by element, e.g. "rawToSignal_SignalsPhysicalID[rawToSignal_SignalsMaxAmplitude > 25]" (the channels of the signals over 25); the cuts select events, e.g. "Sum(rawToSignal_SignalsMaxAmplitude > 25) == 1". A plot with a single histogram can give its keys directly, without histos.

Example:

fiducial: class: "TRestCut" conditions: originX: "trackLineAnalysis_OriginX > 20 && trackLineAnalysis_OriginX < 225" upwards: class: "TRestCut" conditions: downwards: "trackLineAnalysis_Downwards < 0" plots: class: "TRestAnalysisPlot" canvasSize: [1200, 1200] canvasDivisions: [2, 2] save: "Plots_{run.runTag}.pdf" cuts: ["fiducial"] panels:

  • labels:
    • {text: "Run tag: {run.runTag}", position: [0.1, 0.82]}
    • {text: "Mesh: {run.runInfo.meshVoltage}", position: [0.1, 0.74]}
    • {text: "Rate: {entries/runLength|%.1f} per hour", position: [0.1, 0.66]}
    • {text: "Mean angle: {mean(trackLineAnalysis_Angle)} rad", position: [0.1, 0.58]} plots:
  • name: "Spectra" xLabel: "Energy (ADC)" legend: true histos:
    • name: "All" variables: [{name: "trackLineAnalysis_Energy", range: [0, 1e6], nBins: 200}]
    • name: "Upwards" variables: [{name: "trackLineAnalysis_Energy", range: [0, 1e6], nBins: 200}] cuts: ["upwards"] lineColor: "kRed+2"
  • name: "Origin" option: "colz" variables:
    • {name: "trackLineAnalysis_OriginX", range: [0, 250 mm], nBins: 125}
    • {name: "trackLineAnalysis_OriginY", range: [0, 250 mm], nBins: 125}

Migrated from legacy TRestDataSetPlot (JuanAn Garcia, Álvaro Ezquerro), without TRestDataSet: it reads the analysis trees of the files. Differences: the cuts are TRestCut of the manager referenced by name; the panel keys variable, metadata, observable and expression are a single label text with {expressions} (observables with mean(...) etc. instead of names with '_', metadata by instance and key, also the runInfo of the run as run.runInfo.key); YAML lists instead of elements; the TApplication preview waits for Enter.
