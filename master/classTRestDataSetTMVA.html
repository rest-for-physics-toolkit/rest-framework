Detailed Description

Classifier of ROOT TMVA (a boosted decision tree by default) trained with a signal (the reference) and a background dataset, adding its score to the dataset processed. See the class documentation in TRestDataSetTMVA.cxx.

Author
JuanAn García juana.nosp@m.ngp@.nosp@m.uniza.nosp@m.r.es

Multivariate classifier of ROOT TMVA, a process of TRestDataSetProcessManager. A method of TMVA (a boosted decision tree, BDT, by default) is trained to separate a signal, the reference (referenceFileName with the cuts, see TRestDataSetProcess), from a background (backgroundFileName with backgroundCuts), with the observables as input variables; the column <name>_score with its score is added to the dataset processed. For a BDT, the higher the score, the more signal-like the entry.

The events of both samples are split in training and test samples (splitOptions); the method is trained with the first and evaluated with the second. The weights of the trained method (TMVA XML) are stored in the configuration (weights): a dataset processed by this process can be the reference of another, which is then classified with the same method, not trained again.

Parameters

  • observables: columns of the datasets, the input variables of the method.
  • backgroundFileName: background dataset (a pattern must match a single dataset).
  • backgroundCuts: names of the TRestCut of the manager applied to the background.
  • method: method of TMVA (BDT by default; Likelihood, Fisher, MLP...).
  • options: options of the method (TMVA option string, e.g. "NTrees=800:MaxDepth=3" for a BDT).
  • splitOptions: options of TMVA::DataLoader::PrepareTrainingAndTestTree ("SplitMode=Random:NormMode=NumEvents:!V": half of the events of each sample for training).
  • referenceFileName, cuts: the signal, see TRestDataSetProcess.

Results

  • weights: the trained method (TMVA XML).
  • rocIntegral: area under the ROC curve of the test sample.
  • separation: separation of the score between signal and background in the test sample, = 1/2 sum (s - b)² / (s + b) over the bins of the normalized distributions (0 for identical distributions, 1 for disjoint ones).
  • ksSignal, ksBackground: Kolmogorov test of the score between the training and test samples, of the signal and the background (small values: overtraining).
  • variableSeparation: separation of each observable between signal and background (whole samples), in the order of observables, independent of the method.
  • variableImportance: importance of each observable in a BDT (MethodBDT::GetVariableImportance), in the order of observables; empty for the other methods (their ranking is in the log of TMVA, verbose debug).
  • referenceUsed, parametersFileName: see TRestDataSetProcess.

Objects (folder RESTDataSetStore/TRestDataSetTMVA/<name> of the output dataset): the ROC curve of the test sample roc (background rejection versus signal efficiency), the score distributions of the test sample score_signal and score_background, and of the training sample score_signal_train and score_background_train (100 bins).

DrawResults draws the ROC curve, the score distributions (overtraining check) and the separation and importance of the observables; with the macro REST_ViewTMVA of restRoot for a dataset processed by it:

restRoot [0] REST_ViewTMVA("Dataset_Background_TMVA.root", "bdt")

The files of TMVA (TMVA.root, weights/) are not kept. The score is computed with a TMVA::Reader per thread of the data frame.

Example (in a TRestDataSetProcessManager, the cuts defined in the manager):

bdt: class: "TRestDataSetTMVA" referenceFileName: "Dataset_Calibration_Calibrated.root" cuts: ["energy", "tracks"] backgroundFileName: "Dataset_Background_Calibrated.root" backgroundCuts: ["tracks"] method: "BDT" options: "NTrees=800:MinNodeSize=2.5%:MaxDepth=3:BoostType=AdaBoost:AdaBoostBeta=0.5:nCuts=20" observables: ["tckAna_MaxTrack_XYZ_SigmaZ2", "tckAna_MaxTrackEnergyRatio"]

Differences with the TRestDataSetTMVA and TRestDataSetTMVAClassification of the framework pull request #448 (not merged): a single process of a dataset pipeline, training (ComputeParameters) and classification (Apply); a method per process (several processes to compare methods); the weights stored in the dataset instead of a weights file; the cuts are TRestCut of the manager by name.
