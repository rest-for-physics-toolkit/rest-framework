Detailed Description

Abstract base class for metadata and configuration objects.

Instances are configured from YAML nodes or files and define a common lifecycle interface (LoadConfig, Initialize, PrintMetadata).

Every derived class registers its configurable members once (usually in a static initializer of its .cxx) with TRestMetadataFieldRegistry::RegisterField, and itself in MetadataClassRegistry so it can be created from the class key of a YAML section:

static bool registered = [] {
auto& reg = TRestMetadataFieldRegistry::Instance();
reg.RegisterField<TRestCut>("conditions", &TRestCut::fConditions);
MetadataClassRegistry::Instance().Register("TRestCut", ...creator...);
return true;
}();

Only registered keys may appear in the configuration: besides them, every section accepts class, name and verbose (silent, error, warning, info, debug), and any other key throws (CheckConfig). The configuration (with the values actually used) is stored in the output ROOT file as a YAML string in the RESTMetadataStore directory (WriteMetadata), and read back with ReadMetadata / TRestMetadataStore.
