Detailed Description

Abstract base class for all physics event payloads.

Derived events are persisted in ROOT trees and share common event metadata (run IDs, timestamps, status, and subevent tag).

A derived event must implement GetClassName, Initialize (calling TRestEvent::Initialize) and DrawEvent, and usually extends CreateBranches / SetBranchAddresses with its own branches (calling the base versions first). Event types are created by name through EventRegistry, where each event class registers itself.
