Detailed Description

Event viewer of raw signal files (formerly the DrawPulses macro of FEMDAQ): the signals of each event drawn by ASIC, a pad for each ASIC with signals in the event (signal ID = channel + 72 ASIC + 288 card, as written by femclient and TRestRawMultiFEMINOSToSignalProcess), the color by channel.

It reads the tree TRestRawSignalEvent of a REST file; a file being written is followed (TTree::Refresh at the last event). Buttons: open a file, previous and next event, jump to an entry, save the canvas (PDF), quit. Quit, or closing the window, terminates the ROOT application. Launched with the macro REST_Raw_PulsesViewer(fileName) of restRoot:
