Opens the online event display of raw signal files (TRestDAQViewer), e.g. those of femclient.

The window shows, for each readout, the amplitude spectrum, the hit map and the signals of the event, plus the rate; with "DAQ Live Mode" it follows the file while it is written.

Parameters
configFileA YAML of restv2 with the TRestDetectorReadoutManager and the TRestRawSignalAnalysisProcess (e.g. the one of the analysis, or libraries/connectors/examples/ DAQViewer.yaml). Empty: the one of the last session.
dataFileThe REST file with a TRestRawSignalEvent tree. Empty: the one of the last session.
