Detailed Description

Version of the code of REST (rest-for-physics-toolkit), stored in the files it writes (the codeVersion, codeCommit and codeClean of TRestRun and TRestDataSet) and printed by the executables (--version):

  • the version, the VERSION of the project in CMakeLists.txt (e.g. 3.0.0); a release is the tag vX.Y.Z of the commit with that version;
  • the commit of the build (git rev-parse HEAD), "unknown" without git (a build from a tarball or an image can give it with the CMake option REST_GIT_COMMIT);
  • whether the tracked files had uncommitted changes (the files not tracked by git do not count).

They are obtained at each build (cmake/RestVersion.cmake), not only when CMake is configured: a build after a new commit or a change gives the new values.
