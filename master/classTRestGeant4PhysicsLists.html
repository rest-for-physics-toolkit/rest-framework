Detailed Description

The Geant4 physics lists and production cuts of a restG4 simulation (restG4 PhysicsList).

Only the physics lists of fValidPhysicsLists can be used, another name in physicsList is a configuration error (LoadConfig throws): G4DecayPhysics, G4RadioactiveDecayPhysics, G4RadioactiveDecay, G4RadioactiveDecayBase, G4Radioactivation, G4EmLivermorePhysics, G4EmPenelopePhysics, G4EmStandardPhysics_option3, G4EmStandardPhysics_option4, G4HadronElasticPhysicsHP, G4IonBinaryCascadePhysics, G4HadronPhysicsQGSP_BIC_HP, G4NeutronTrackingCut and G4EmExtraPhysics. 

physicsG4:
  class: "TRestGeant4PhysicsLists"
  cutForGamma: 1 mm               # production cuts (range)
  cutForElectron: 2 mm
  cutForPositron: 1 mm
  cutForMuon: 1 mm
  cutForNeutron: 1 mm
  minEnergyRangeProductionCuts: 1 keV
  maxEnergyRangeProductionCuts: 1 GeV
  ionLimitStepList: ["F20", "Ne20"]
  physicsList:
    - name: "G4EmLivermorePhysics"
      option:
        - name: "pixe"
          value: "true"
    - name: "G4DecayPhysics"
    - name: "G4RadioactiveDecayPhysics"
    - name: "G4HadronElasticPhysicsHP"
    - name: "G4HadronPhysicsQGSP_BIC_HP"
