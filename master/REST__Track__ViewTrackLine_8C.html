int REST_Track_ViewTrackLine (const std::string &fileName, const std::string &prefix="", const std::string &g4Prefix="")
 Browses the events of a file analysed with TRestTrackLineAnalysisProcess (TRestBrowser: entry, event ID, event type, selection with observables, previous/next event) with TrackLineViewer: the track and hits events with the origin and end over them (reconstructed in black, Geant4 in red for simulated files), the raw and detector signal events split in X and Y strips (readout of the file). The event type is chosen in the browser, at start the last saved event type of the file (TRestRun::GetOutputEvent, e.g. TRestTrackEvent). prefix is the name of the TRestTrackLineAnalysisProcess whose observables are drawn (branches prefix_OriginX, ...); if empty, the first process of the file with them. The plot option is the DrawEvent option of the event (for signals, any option draws them without splitting).

Browses the events of a file analysed with TRestTrackLineAnalysisProcess (TRestBrowser: entry, event ID, event type, selection with observables, previous/next event) with TrackLineViewer: the track and hits events with the origin and end over them (reconstructed in black, Geant4 in red for simulated files), the raw and detector signal events split in X and Y strips (readout of the file). The event type is chosen in the browser, at start the last saved event type of the file (TRestRun::GetOutputEvent, e.g. TRestTrackEvent). prefix is the name of the TRestTrackLineAnalysisProcess whose observables are drawn (branches prefix_OriginX, ...); if empty, the first process of the file with them. The plot option is the DrawEvent option of the event (for signals, any option draws them without splitting).

Parameters
fileNameREST file analysed with TRestTrackLineAnalysisProcess (e.g. the output of libraries/track/examples/TrackLinearization.yaml).
prefixName of the TRestTrackLineAnalysisProcess instance whose observables are drawn; empty: the first process of the file with them.
g4PrefixPrefix processName_volume of the TRestGeant4AnalysisProcess observables EntryX/Y/Z and EndX/Y/Z drawn (e.g. "g4Ana_gas"); empty: the first one of the file with them.
Returns
Always 0 (the browser window stays open).
