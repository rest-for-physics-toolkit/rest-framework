Detailed Description

The main class to store the Geant4 simulation conditions that will be used by restG4.

It is read by restG4 (inside a TRestGeant4Manager) and stored in the output file with the values used and the tables of the simulation: the volume, particle and process names of the IDs stored in the TRestGeant4Event (volumeNameMap, particleNamesMap, processNamesMap, processTypesMap), the Geant4 version and the number of events. When written to a file, the geometry is stored as well (Geometry), and it is loaded again when the metadata is read (any run made from a simulation file keeps it). Units: keV, mm, us. 

geant4Metadata:
  class: "TRestGeant4Metadata"
  gdmlFilename: "geometry/setup.gdml"  # GDML geometry
  nEvents: 1000              # events to simulate
  nRequestedEntries: 0       # stop when this number of events is stored (0: no limit)
  simulationMaxTimeSeconds: 0  # stop after this wall time (0: no limit)
  seed: 17021981             # 0: a random one, written back
  subEventTimeDelay: 100 us  # a hit later than this starts a new sub-event
  fullChain: true            # full radioactive decay chain or a single decay
  fullChainStopIsotopes: ["Pb210"]  # the chain stops at these isotopes
  resetGlobalTime: true      # reset the global time after a long radioactive decay
  resetTimePrecision: 1.0    # us
  energyRangeStored: [0, 5 MeV]  # events stored with sensitive energy in this range
  saveAllEvents: false       # store also the events without energy in the sensitive volumes
  storeTracks: true          # false: only the event summary (energies, primaries)
  storeHadronicTargetInfo: false  # target nucleus of the hadronic processes in the hits
  removeUnwantedTracks: false     # keep only the tracks with energy in the active volumes
  removeUnwantedTracksKeepZeroEnergyTracks: false
  printProgress: false
  magneticField: [0, 0, 0]   # world magnetic field (T)
  activeVolumes:             # TRestGeant4ActiveVolumeMetadata
    - name: "gas"
      maxStep: 1 mm
      sensitive: true
  killVolumes: ["shielding"] # particles entering them are killed
  biasingVolumes: []         # TRestGeant4BiasingVolume
  generator:                 # TRestGeant4PrimaryGeneratorInfo, see TRestGeant4PrimaryGenerator
    type: "volume"
    from: "gas"
    source:
      use: "Xe136bb0n.dat"

Also:

  • activateAllVolumes: true: all the physical volumes of the geometry are active (their hits are stored), with chance 1 and no step limit; the activeVolumes entries keep their values (and only they and the sensitive ones are kept by removeUnwantedTracks). Default false.
  • registerEmptyTracks: false: the tracks without hits in the stored volumes (only their initial hit, always stored, outside the active volumes or the ones not stored in the event by their chance) are removed from the stored events, to save space; their children keep their parent ID (the parent is not stored). Default true (all the tracks are stored).
  • biasingVolumes (TRestGeant4BiasingVolume): volume biasing in stages, see below.

Also registered: geant4Version, geometryPath, the ID tables and the biasing results (biasingTotalFactor, biasingStageEvents, biasingStageParticles), written by restG4.

Volume biasing

With N biasingVolumes (nested virtual volumes, from the outermost to the innermost), restG4 runs N + 1 stages in one execution. Stage 0 simulates nEvents events of the generator; in stage k (k < N) a particle entering volume k is stopped and, if its kinetic energy is in the energyRange of the volume, its state at the crossing point is stored; stage k + 1 simulates each stored particle biasingFactor (of volume k) times as the primary of a new event. The last stage (N) is a normal simulation, and only its events are written to the output. Every output event has the same weight 1 / biasingTotalFactor, the product of the factors of the volumes. The results of the stages are stored:

  • biasingTotalFactor: product of the biasingFactor of the volumes (1 without biasing).
  • biasingStageEvents: events simulated in each stage (N + 1 values, the first one is nEvents).
  • biasingStageParticles: particles stored in stage k when entering volume k (N values).

The normalization getters: GetNumberOfEvents is the number of primaries of the generator simulated (in stage 0); GetEquivalentNumberOfEvents is the number of primaries the output represents, nEvents times the total factor (times GetBiasingCompletedFraction if the simulation ended early); GetBiasingEventWeight is the weight of each output event. Without biasingVolumes the equivalent number is nEvents and the weight 1.

◆ GetBiasingCompletedFraction()

double TRestGeant4Metadata::GetBiasingCompletedFraction ( ) const

Fraction of the biasing stages completed: the product, over the stages after the first one, of the events simulated over the events planned (particles stored in the previous stage times its factor; a stage with nothing planned counts 1). It is 1 without biasing or when all the stages were completed (also when a stage stored no particle), below 1 when the last stage was stopped early (requested entries, time limit) and 0 if the simulation stopped (time limit, CTRL-C) before the last stage with stored particles not simulated (the output has no events). For merged metadata it is computed from the summed counts (exact when all the stages were completed)
