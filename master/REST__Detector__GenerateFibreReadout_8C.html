Builds a TRestFibreReadout from the readout section of a YAML file (BuildGeometry, with the decoding file of the configuration if given) and exports it, with its decoding named decodingName ("nominal_decoding" by default), to a ROOT file that a TRestDetectorReadoutManager can import (instanceName: the name of the readout, decodingName: the same name). If gdmlFile is given, it also writes there the placements of the fibres (TRestFibreReadout::WriteGDMLPlacements), to include in the GDML of the simulation as an external entity inside the volume of the scintillator:

<!DOCTYPE gdml [ <!ENTITY fibres SYSTEM "fibres.xml"> ]> ... <volume name="chamberVolume"> <materialref ref="LiquidScintillator"> <solidref ref="chamberSolid"> &fibres; </volume>

The readout is kept in the global fibreReadout (nullptr if it cannot be built).

Parameters
yamlFileYAML file with a readout section of class TRestFibreReadout.
outputFileROOT file written (RECREATE).
gdmlFileFile with the placements of the fibres (empty: not written).
decodingNameName of the decoding stored with the readout.
checkOverlapsChecks the overlaps of the geometry (TRestDetectorReadout::CheckOverlaps) before exporting it: nothing is written if there is any.
Returns
0 on success, 1 on any error; as exit code (e.g. in a CI): restRoot -b -q -e 'gSystem->Exit(<macro>(...));'

Usage in restRoot:

restRoot [0] REST_Detector_GenerateFibreReadout("LiquidO.yaml", "LiquidO_readout.root", "geometry/fibres.xml")
