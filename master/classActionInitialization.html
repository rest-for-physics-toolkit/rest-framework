Detailed Description

Creates the user actions of restG4 for the master and the worker threads.

The master thread only gets a RunAction. Each worker thread (or the single thread in serial mode) gets its OutputManager (SimulationManager::InitializeOutputManager) and the PrimaryGeneratorAction, RunAction, EventAction, SteppingAction, StackingAction and TrackingAction.
