Detailed Description

Converts the ROOT files of feminos-daq (https://github.com/rest-for-physics/feminos-daq) into TRestRawSignalEvent.

The input file is the inputFileName of the TRestRun, with the trees events (timestamp in ms, signal_ids, signal_values: the samples of all the signals one after the other) and run. The event ID is the entry of the events tree.

With useFeminosDaqRunInfo (true) the run takes from the run tree its number, tag, description (comments) and start time (the ones not empty, they replace the configuration and the input file name), and adds to runInfo the detector, driftField (V/cm/bar), meshVoltage (V) and pressure (bar), unless the configuration already gives them. Otherwise, or if the run tree has no timestamp, the start time is the one of the first event. The end time is always the one of the last event. No observables.

Example (see libraries/raw/examples/FeminosRootToRaw.yaml):

feminosRootToSignal:
class: "TRestRawFeminosRootToSignalProcess"
useFeminosDaqRunInfo: true
