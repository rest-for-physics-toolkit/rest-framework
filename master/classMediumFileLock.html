Detailed Description

Exclusive lock (flock) of the directory of a medium file while it is read or written, so several restGarfield processes can add tables to the same file (e.g. the media Ar99_iC4H10_1, Ar98_iC4H10_2... of ArIso.root). It waits for the lock of another process and releases it when destroyed.
