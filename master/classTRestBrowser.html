Detailed Description

Event browser of REST files: a ROOT TBrowser with a control panel (entry, event ID and subID, event type, plot option, open file, exit) on the left, the event viewer (TRestEventViewer or a derived viewer) on the right, and a selection box with previous/next buttons at the bottom.

The file is opened with a TRestRun; the selected event type is the last saved event of the file (TRestRun::GetOutputEvent). The selection is an expression of the analysis tree observables (TTreeFormula) used to jump to the previous/next entry passing it. Opened, e.g., with the macro REST_ViewEvents.

Author

This class opens input file with TRestRun and shows the plot of each event The plot is shown through TRestEventViewer interface on the right. On the left there is a control bar to switch the events. Plot options can also be given.
