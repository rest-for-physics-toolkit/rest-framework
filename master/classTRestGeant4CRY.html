Detailed Description

The configuration of CRY (Cosmic-ray Shower Library, LLNL) for the cry generator of restG4: a section of the TRestGeant4Manager, as the physics lists; the generator only places its plane in the geometry. See TRestGeant4CRY.cxx for the options.

Each field is the YAML key without the f prefix and with the first letter in lower case (e.g. fSubBoxLength is subBoxLength).

Author
Javier Galán javie.nosp@m.r.ga.nosp@m.lan@u.nosp@m.niza.nosp@m.r.es
JuanAn García juana.nosp@m.ngp@.nosp@m.uniza.nosp@m.r.es

The configuration of CRY (Cosmic-ray Shower Library, LLNL) for the cry generator of restG4 (TRestGeant4SpatialGeneratorCRY): a section of the TRestGeant4Manager, as the physics lists, linked to the generator when the configuration is loaded (TRestGeant4Manager::LoadConfig; a cry generator without this section is an error, the section is not used with another generator). restG4, built with CRY, calls CRY during the simulation: each event is a shower with all its particles. This class does not depend on CRY. It is stored in the output file with the other metadata.

Parameters

  • particles: the particles returned by CRY, a list of muons, neutrons, protons, gammas, electrons (electrons and positrons), pions and kaons (all by default), e.g. ["muons"] for only the muons. The showers keep only those particles (and a shower without any of them is not returned); the exposure is the same (the time simulated by CRY does not depend on the particles kept). Legacy returnMuons... : the particles with true.
  • nParticlesMin, nParticlesMax: showers with less or more particles are not returned (1, 1000000).
  • date: month-day-year, for the 11-year solar cycle ("7-1-2012").
  • latitude: geomagnetic latitude in degrees, -90 to 90 (90).
  • altitude: 0, 2100 m or 11300 m, the altitudes of the CRY data tables (0).
  • subBoxLength: side of the horizontal square where the particles start, needed: the particles outside it are not returned. It can be larger than the world: restG4 generates only the particles crossing the world, from where they enter it, and skips the showers without any (they count in the exposure).
  • maxExposureTime: the simulation stops when CRY has simulated this time (0: no limit, only nEvents; with nEvents 0 only this one).

The seed of CRY is the one of the simulation (TRestGeant4Metadata) plus the index of each thread, which has its own CRY (the exposure is the sum of all). The CRY offsets (xoffset, yoffset, zoffset) are not used: the square is placed in the geometry by the position and verticalAxis of the generator. The exposure simulated is stored in the generator section (TRestGeant4Metadata::GetCRYExposureTime), to normalize to a rate.

Example:

g4Manager: class: "TRestGeant4Manager" ... cry: class: "TRestGeant4CRY" particles: ["muons", "neutrons"] # all by default latitude: 42 altitude: 0 subBoxLength: 3 m maxExposureTime: 1 day geant4Metadata: class: "TRestGeant4Metadata" ... generator: type: "cry" position: [0, 1 m, 0] # center of the CRY square verticalAxis: [0, 1, 0] # the CRY up: the showers go down along -Y

Migrated from legacy TRestGeant4ParticleSourceCry: the options in their own section, the whole shower per event and the exposure stored.
