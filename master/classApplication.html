Detailed Description

The restG4 application: reads the configuration, runs the Geant4 simulation and writes the output file.

The configuration file must have a section of class TRestGeant4Manager, with a TRestRun, a TRestGeant4Metadata and a TRestGeant4PhysicsLists. The parameters of the file and the –set of the command line are resolved by TRestYAMLUtils, and the GDML file is searched relative to the configuration file (then in the geometryPath of the metadata).

void Application::Run ( const CommandLineOptions::Options &  options)

Runs the simulation with the options of the command line.

Applies the options to the metadata, creates the output file of the TRestRun, the run manager (serial or multithreading) and the user initializations, simulates nEvents (/run/beamOn), writes the geometry and the metadata (TRestRun, TRestGeant4Metadata, TRestGeant4PhysicsLists) and checks the output file. With biasingVolumes (nested, nEvents required) it runs the biasing stages (RunBiasingStages). With –update-gdml it only writes the parameters in the GDML files and exits. Fatal configuration errors end the program (exit(1)).
