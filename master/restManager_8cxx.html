Detailed Description

restManager: command line entry point of TRestManager (YAML-based configuration).

Usage:

restManager –c|–config <config.yaml> [–i|–input <input.root>] [–o|–output <output.root>] [–v|–verbose <level>] [–e|–events <n>] [–j|–threads <n>] [–r|–reference <process>=<dataset>] [–set <name>=

] [–maxRepeated <n>] [–repeatedInterval ] restManager –version

Reads the TRestManager section of the configuration, applies the command line overrides, runs it (TRestManager::Run), saves its metadata and draws its plots (TRestManager::RunPlots).

Options (each one takes a value; an unknown option prints the usage and exits with 1):

  • --c, --config: YAML configuration file with a TRestManager section (required).
  • --i, --input: input file. It sets the inputFileName of the TRestRun; with a TRestDataSet (dataset generation) its filePattern; with a TRestDataSetProcessManager and no TRestDataSet its inputFileName; with no run nor dataset, the inputFileName of every TRestAnalysisPlot.
  • --o, --output: output file. It sets the outputFileName of the TRestRun, of the TRestDataSetProcessManager if any, otherwise of the TRestDataSet.
  • --v, --verbose: global verbose level (TRestLogManager::GetVerboseLevelFromString).
  • --e, --events: eventsToProcess of the TRestEventProcessManager.
  • --j, --threads: nThreads of the TRestEventProcessManager (ROOT thread safety is enabled with more than one thread).
  • --set: sets a parameter of the section parameters of the configuration for this execution (repeatable; the file is not changed), e.g. --set meshVoltage=300V. A parameter not used by the configuration (or the geometries it reads) is an error.
  • --maxRepeated: number of similar messages (warning and info) from the same line of the code that, arriving within a time window of --repeatedInterval seconds, make the next ones be suppressed for ever (default 10, 0: no suppression); with verbose debug none is suppressed.
  • --repeatedInterval: time window in seconds of --maxRepeated (default 10 s, 0: a single window for the whole execution).
  • --r, --reference: sets the referenceFileName of a process of the TRestDataSetProcessManager (repeatable), e.g. --r calib=D_00120_00122_Calibration.root.
  • --version: prints the version of the code (REST_Version::GetSummary) and exits; it is also printed at the start of each execution and stored in the output files.

SIGINT, SIGTERM, SIGHUP and SIGQUIT request a clean stop (TRestManager::RequestStop).
