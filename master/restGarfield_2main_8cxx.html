Detailed Description

restGarfield: computes with Garfield++ the tables of a TRestDetectorTransportManager configuration

restGarfield config.yaml [–set name=value ...] [–jobs N] restGarfield –version

--set sets a parameter of the section parameters of the configuration for this execution (repeatable; the file is not changed). --jobs N splits the field nodes of each gas transport table and the start points of each drift response and the avalanches of each amplification response in up to N processes (Garfield++ is not thread safe; default 1). Any other argument is an error.

transportManager: class: "TRestDetectorTransportManager" medium: class: "TRestDetectorMedium" name: "ArIso" state: "gas" components: {Ar: 99, iC4H10: 1} transport: fieldRange: [10 V/cm, 1000 V/cm] gain: gap: 128 um reducedFieldRange: [25 kV/cm/bar, 35 kV/cm/bar]

The tables go to the mediumFile of the medium (by default <name>.root): first the transport tables, then the gain tables; then the drift responses in field maps (drift, each one in its responseFile) and the amplification responses in the field maps of a unit cell (amplification, each one in its responseFile). The classes are in the detector library (they do not depend on Garfield++); this package only computes the tables and responses.
