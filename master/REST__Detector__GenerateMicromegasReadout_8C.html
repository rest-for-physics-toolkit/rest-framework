Builds a TRestMicromegasReadout from the readout section of a YAML file (BuildGeometry, with the decoding file of the configuration) and exports it, with its decoding named decodingName ("nominal_decoding" by default), to a ROOT file that a TRestDetectorReadoutManager can import (instanceName: the name of the readout, decodingName: the same name). The readout is kept in the global mmReadout (nullptr if it cannot be built).

Parameters
yamlFileYAML file with a readout section of class TRestMicromegasReadout.
outputFileROOT file written (RECREATE).
decodingNameName of the decoding stored with the readout.
checkOverlapsChecks the overlaps of the geometry (TRestDetectorReadout::CheckOverlaps) before exporting it: nothing is written if there is any.
Returns
0 on success, 1 on any error; as exit code (e.g. in a CI): restRoot -b -q -e 'gSystem->Exit(<macro>(...));'

Usage in restRoot (from the examples directory):

restRoot [0] REST_Detector_GenerateMicromegasReadout("MicromegasReadout.yaml", "iaxo_readout_output.root")
