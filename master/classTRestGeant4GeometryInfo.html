Detailed Description

Lightweight API and cache manager built on top of ROOT TGeoManager for simulation geometries.

Part of TRestGeant4Metadata. It keeps:

  • the TGeoManager of the geometry (from the GDML in restG4, or the Geometry stored in the file);
  • the volume ID map: the ID of each Geant4 physical volume name, the IDs stored in the hits of TRestGeant4Event (filled by PopulateFromGeant4World in restG4, stored in the metadata);
  • in restG4 only, the logical volume name ("alternative name") of each Geant4 physical volume.

The volume expressions are regular expressions (TPRegexp, matched anywhere in the name, e.g. "^gas" for the names starting with gas) of physical or logical volume names.
