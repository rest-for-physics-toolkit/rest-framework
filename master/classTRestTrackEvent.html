Detailed Description

Event holding a collection of particle tracks. Each track is a contiguous run of volume hits (position + energy + time + type + sigma) inside the shared fData storage; no per-track object is allocated.

An event holds the tracks of one processing stage only: a track process writes its tracks to a new event instead of adding them as children of the input tracks. Each track is self-contained (it stores its own representation of the hits, e.g. the reduced nodes), so it does not need the hits or the tracks of the previous stages to be stored. The parent ID is the ID of the track it comes from in the input event of the stage (0 if none), for reference only.

The tracks are addressed by their index in the event (0 to GetNumberOfTracks() - 1) or by their ID (GetTrackById); the hits of a track by their index inside the track. TRestTrack is a view of one track. The type of a track is the type of its hits (TRestHitsData::REST_HitType, e.g. XZ and YZ for strip readouts, XYZ for 3D readouts); the coordinates a hit does not define are NaN.

Tree branches: fHitX, fHitY, fHitZ, fHitTime, fHitEnergy, fHitType, fSigmaX, fSigmaY, fSigmaZ (one entry per hit, the tracks back-to-back), fTrackID, fParentID and fTrackNHits (one entry per track).

Building an event, hit by hit or from a TRestHits:

int index = event.AddTrack(trackID, parentID);
event.AddHitToTrack(position, energy, time, type, sigma); // repeat for every hit, in order
event.AddTrack(trackID2, parentID2, hits, sigmas);

Some getters take a projection option, kept from legacy for strip readouts, with the same meaning in all of them: "X" selects only the XZ tracks, "Y" only the YZ tracks and "XYZ" only the XYZ (3D) tracks; any other option selects no track. The empty option "" is the XYZ tracks in GetMaxEnergyTrack and the methods based on it, and all the tracks in GetNumberOfTracks and GetEnergy (as without option).

The initial nodes are equally spaced along the hits order; the new track ID is the number of tracks of output + 1, and the nodes get the hit type of the first hit and no time.
