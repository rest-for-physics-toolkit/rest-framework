Particles and isotopes produced in a restG4 simulation (legacy REST_Geant4_ListIsotopes, REST_Geant4_FindIsotopes and REST_Geant4_FindGammasEmitted): the number of tracks of each particle but e-, e+ and gamma (isotopes, alphas, neutrons...), in decreasing order, with the volumes where they are created (GetInitialVolume), written also to outputFile if given ("name count" per line, as legacy); and the spectrum of the initial kinetic energy (keV) of the gammas, drawn, in [gammaMin, gammaMax] (the whole range if gammaMax <= gammaMin) with bins bins.

Parameters
fileNamerestG4 file with TRestGeant4Event (with tracks).
outputFileText file for the particle counts (not written if empty).
gammaMinMinimum of the gamma spectrum (keV).
gammaMaxMaximum of the gamma spectrum (keV); the whole range if gammaMax <= gammaMin.
binsNumber of bins of the gamma spectrum.
Returns
0 on success, 1 if the file has no TRestGeant4Event.
