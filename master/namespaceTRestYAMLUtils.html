◆ ResolveRefs()

YAML::Node TRestYAMLUtils::ResolveRefs ( const YAML::Node &  root,
const std::map< std::string, std::string > &  overrides = {},
bool  setCurrentParameters = true 
)

Node with ${ENV:VAR} replaced by the environment variable VAR (empty if it is not defined), ${PARAM:name} by the parameter name and ${a.b} by the scalar at the path a.b of the node. Throws if a reference is not found or is not a scalar. The replaced values of ${PARAM:name} and ${a.b} are resolved again (they can have references); a reference that contains itself (e.g. a: "${a}") throws (more than 1000 substitutions in a value). Thread safe (the parameters are global, see GetParameters).

Parameters: the section parameters at the root of the configuration, name: value (a number, with units or not, or a text) or ${ENV:VAR}, e.g. 

parameters:
  isotope: "U238"
  foilThickness: 5 um

They are used in the configuration as ${PARAM:isotope} (a parameter not defined is an error) and, in restG4, they replace the GDML constants and entities with the same name (TRestGDMLParser::Resolve). overrides (the --set name=value of the executables) replace their values for this execution (the file is not changed); a name that is not in parameters is an error. The section is removed from the returned node (the configurations stored are the resolved ones); its values are kept as the current parameters (GetParameters), those of the last configuration resolved, unless setCurrentParameters is false (another file read by a metadata, TRestMetadata(fileName, section): the parameters of the main configuration and those used are kept).

Conditional blocks: a map with select and cases is replaced, after the parameters are resolved, by the case whose name is the value of select (default if none matches; neither is an error), merged over the other keys of the map (common to all the cases; the maps are merged recursively and the case wins). Only the case chosen remains in the returned node (the configuration stored); the parameters of all the cases must be defined. A case can be a scalar (then the block has no other keys). E.g. 

parameters:
  generator: "Gammas"
...
generator:
  select: "${PARAM:generator}"
  source:                      # common to all the cases
    particle: "gamma"
  cases:
    Gammas:
      type: "point"
    SolarAxions:
      type: "surface"
      shape: "circle"
energy:
  select: "${PARAM:generator}"
  cases: {Gammas: 5.5 MeV, default: 10 MeV}
