TGeoManager * ReadGeometry (TDirectory *folder, const std::string &key="Geometry")
 Geometry key of a folder, read once per process: the same file and key give the same TGeoManager (cached, never deleted), so the metadata of several TRestRun of the same file (e.g. one per thread of restManager) share it, and reading it does not delete another geometry (TGeoManager::Init deletes gGeoManager). Thread safe. gGeoManager becomes this geometry only if there was none. nullptr if the folder has no geometry.
 
TGeoManager * ReadGeometryCopy (TDirectory *folder, const std::string &key="Geometry")
 A new copy of the geometry key of a folder, owned by the caller, for a geometry navigated (FindNode, cd) by each thread, e.g. the readouts (one per thread of restManager): a TGeoManager cannot be navigated by several threads. Read with the same lock as ReadGeometry, without deleting gGeoManager; gGeoManager becomes this geometry only if there was none. nullptr if the folder has no geometry.
 
std::string ReadGeometryHash (TDirectory *folder, const std::string &key="Geometry")
 Hash of the geometry key of a folder: the one written with it or, if there is none (files written before), computed reading the geometry (slow; the current gGeoManager is kept). Empty if the folder has no geometry.
 
void DeleteGeometry (TGeoManager *geometry)
 Deletes a geometry (e.g. one of ReadGeometryCopy) with the same lock as ReadGeometry: ~TGeoManager sets gGeoManager and gGeoIdentity to nullptr, so they are restored afterwards unless the deleted geometry was the current one (gGeoIdentity is taken from the current geometry if it belonged to the deleted one). nullptr does nothing. Use it instead of delete (or a std::unique_ptr) for any TGeoManager.
