Detailed Description

Abstract base for event-processing pipeline stages.

A process consumes an input event and writes into an output event object. Returning false from ProcessEvent indicates that the event is rejected. The event is also rejected after the process if it does not pass the TRestCut of cuts (names of TRestCut in the manager).

Common configuration keys of every process (besides those of the derived class):

pipeline:
class: TRestEventProcessManager
myProcess:
class: TRestSomeProcess
verbose: info
observables: ["all"] # names offered by the process, "all" or "none" (default)
cuts: ["fiducial"] # TRestCut of the manager applied after the process

The observables are written in the analysis tree as <processName>_<observable>. A name in observables that the process does not offer throws at initialization.

A derived process implements GetInputEvent / GetOutputEvent (event class names; "None" as input for a generator creating the events, empty for processes of any event type taking the event of the previous one), InitProcess (registering its observables with RegisterObservable) and ProcessEvent.
