Detailed Description

Data taking of a set of FEMs: commands, event builder and output files. The derived classes implement each electronics (FEMDAQARCFEM: ARC and FEMINOS, FEMDAQDCC: DCC, TCM).

The files are REST run files (TRestRun of the configuration): the events in the tree TRestRawSignalEvent (written as TRestRawDAQSignalEvent, with the information of each FEM), and the TRestRun and TRestRawDAQMetadata as metadata.

During a run (startDAQ) two threads of this class run besides the ones of the electronics: the event builder (eventBuilderThread, implemented by the derived class), which builds the events from the data of the FEMs and writes them, and the update thread (UpdateRunThread, UpdateThread), which writes the rate, updates the Prometheus metrics and ends the run at nEvents or time.
