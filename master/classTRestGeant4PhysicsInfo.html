Detailed Description

Class to store and map Geant4 process names, particle names, and process types to unique integer identifiers.

Part of TRestGeant4Metadata, filled by restG4 while simulating (thread safe insertions): the particle IDs are the PDG encodings, the process IDs Geant4 process type * 1000 + subtype (processes sharing type and subtype, e.g. eIoni and ionIoni, share the ID and the first name inserted is kept).
