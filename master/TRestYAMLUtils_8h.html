YAML::Node TRestYAMLUtils::LoadConfigFile (const std::string &fileName)
 A YAML configuration file with its include keys expanded, at any depth: a map with include: "file.yaml" takes the content of that file (a map, the keys of the section) and its own keys override it (the maps are merged recursively, lists and scalars replaced); include: "file.yaml:key" takes the section key of a file with several. The file can be a URL (downloaded and cached, TRestTools::GetLocalFile; e.g. a versioned file of rest-common), and so the main file; the relative includes of a URL are relative to its URL. The path is relative to the file that includes it (absolute paths and ${ENV:VAR} are accepted; not ${PARAM:...}: the parameters are resolved after, by ResolveRefs, with the parameters of the main file only). YAML::Node TRestYAMLUtils::ResolveRefs (const YAML::Node &root, const std::map< std::string, std::string > &overrides={}, bool setCurrentParameters=true)
 Node with ${ENV:VAR} replaced by the environment variable VAR (empty if it is not defined), ${PARAM:name} by the parameter name and ${a.b} by the scalar at the path a.b of the node. Throws if a reference is not found or is not a scalar. The replaced values of ${PARAM:name} and ${a.b} are resolved again (they can have references); a reference that contains itself (e.g. a: "${a}") throws (more than 1000 substitutions in a value). Thread safe (the parameters are global, see GetParameters).

void TRestYAMLUtils::SetValuesInFile (const std::string &fileName, const std::vector< std::pair< std::string, std::string > > &values)
 Sets values of a YAML file in its text, keeping the rest as it is (comments, order, format): each (path of keys separated by dots, e.g. "run.runInfo.operator"; value). A value is written plain if it reads back the same, otherwise double quoted. A key that is not there is added at the start of its map, and so are its missing parent keys (e.g. a value of a section taken from an included file: it is written in this file, overriding the included one). Throws if a path cannot be set (a parent that is not a block map, a value that is not a scalar of one line).
