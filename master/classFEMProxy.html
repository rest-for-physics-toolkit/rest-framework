Detailed Description

A FEM (or the TCM) in the data taking: its socket plus the state shared by the threads (command replies, request credits, received data, event being built, log file).

The receiver thread appends the data frames to tmpBuffer (under mutex_mem); the event builder moves them to buffer and extracts the events from it.
